# FitProgress — система учёта и анализа спортивных тренировок

Самостоятельный учебный веб-проект по теме «Веб-приложение для учёта и анализа спортивных тренировок».

## Что работает
- Запись тренировок по дате, виду спорта, продолжительности и заметкам
- Добавление подходов с весом, количеством повторений или временем
- Каталог упражнений с группами мышц и описанием; добавление новых упражнений
- Дневник с удалением записей и сохранением тренировки как шаблона
- Повторный запуск тренировки из шаблона
- Динамика максимального веса и объёма по упражнению, личный рекорд
- Сводка нагрузки по группам мышц за последнюю неделю
- Сравнение текущего месяца с предыдущим по количеству занятий, суммарному объёму и средней длительности
- Адаптивный русскоязычный веб-интерфейс

## Технологии
Frontend: React 19, TypeScript, Vite, Recharts, Lucide. Backend: Node.js, Fastify, TypeScript, PostgreSQL (`pg`). Tests: Node.js test runner.

## Требования
- Node.js 22+
- Docker Desktop (для PostgreSQL)

## Запуск в Windows PowerShell

Из корня проекта:

```powershell
docker compose up -d
cd backend
Copy-Item .env.example .env
npm install
npm run dev
```

В **другом** окне PowerShell:

```powershell
cd frontend
npm install
npm run dev
```

Приложение: **http://localhost:5173**. API: **http://127.0.0.1:3001/health**.

База и справочник упражнений создаются автоматически при первом запуске backend. Docker PostgreSQL работает на порту 5433 хост-компьютера, чтобы не конфликтовать с другой локальной базой.

## Ограничения текущей версии
- Один локальный профиль, **без регистрации и облачной синхронизации**. Не используйте на публичном сервере без аутентификации.
- Данные PostgreSQL не шифруются на уровне приложения.
- Корректно работает с весовыми подходами и статическими упражнениями, но объём в кг применим только к подходам с весом.
- Не предоставляет медицинские советы.

## Переключение языка (RU / EN)

Переключатель **RU / EN** находится в верхней панели справа. Вся стандартная навигация,
формы, сообщения, графики, даты и числовые подписи отображаются на выбранном языке.
Выбор сохраняется в `localStorage` (`fitprogress-language`) при перезагрузке страницы.

Названия предустановленных упражнений переводятся только при отображении: данные в
PostgreSQL не меняются. Пользовательские названия, заметки и названия шаблонов
остаются в том виде, в каком пользователь их ввёл. Переключение языка не удаляет
записанные тренировки и не требует миграции базы данных.

## Вес одного подхода и тренировочный объём

В интерфейсе **максимальный вес** обозначает фактически записанный вес в одном
подходе. Например, пользователь вводит **20 кг** и **10 повторений**: на главной
отображается вес **20 кг**, а не 200 кг.

**Тренировочный объём** — отдельная расчётная величина: `вес × повторения`.
Для указанного примера объём = 200 кг. Он отображается с пояснением в дневнике
и разделе аналитики, но не подменяет фактический вес. Исторические записи в
PostgreSQL не изменяются.

## Обновление: читаемые показатели и управление тренировками

- По умолчанию в аналитике показывается **фактический максимальный рабочий вес** (например, 20 кг при 10 повторениях), а не сумма произведений.
- Переключатель «Вес / Объём» в аналитике раскрывает расчётный объём, когда это действительно нужно. Объём за месяц сохраняется для требования практики, но не выдаётся за вес снаряда.
- Редактирование сохранённой тренировки: в дневнике нажмите значок карандаша, измените подходы и сохраните. API `PUT /api/workouts/:id` обновляет данные в одной транзакции; неверный запрос не меняет существующую запись.
- Фильтры по дате «С даты / По дату» на странице дневника.

## Проверка (Node.js 22+)

```powershell
cd backend
npm ci
npm test
npm run build
# при работающем API на http://127.0.0.1:3001:
npm run test:api

cd ../frontend
npm ci
npm test
npm run build
```

`test:api` создаёт и удаляет **только свою временную запись** и проверяет создание, редактирование и удаление через HTTP. Для интеграционного теста требуется локально запущенная PostgreSQL и backend. Остальные unit-тесты не требуют БД. Запуск визуального E2E (например, браузерные клики) не заменяется этими тестами.
